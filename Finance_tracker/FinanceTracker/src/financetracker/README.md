# Overview

This is a basic scalable finance tracker. The purpose is to track basic income vs spending to help you identify where money is coming and going. 

Json is not a native file for Java, so I chose to include a txt file instead for easier handling, with formatted strings that seperated valuse with the "<&>" Characters. (because it is not very probable that that would ever be a value in any data stored.)

I am always looking for free reliable software to help me become organized, and I was looking for a software to try to manage my finances better. I elected to create one.
